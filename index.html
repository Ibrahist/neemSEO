User Manual

How to Use neemSEO

Follow these simple steps to start auditing pages, crawling sites, tracking ranks, and plugging in your AI coding agents.

1

Start the neemSEO Backend Server

FastAPI & Uvicorn

neemSEO runs locally on your machine or container. From your terminal in the project directory, run:

python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload

Once started, open http://127.0.0.1:8000/ in your browser to access the interactive web dashboard.

2

Run an Instant On-Page Audit

In the web dashboard under the Page Auditor tab:

  1. Enter your target URL (e.g. https://example.com).
  2. Optionally enter a focus target keyword to evaluate density and placement.
  3. Check the Include Google Core Web Vitals box if you want LCP, CLS, and INP metrics.
  4. Click Run On-Page Audit. Review your Health Score (0–100), letter grade, and prioritized recommendations.
3

Audit Whole-Site Link Graph & Broken Links

Switch to the Site Crawler tab to audit multiple pages:

  1. Provide your homepage or sitemap.xml URL.
  2. Set maximum pages (e.g. 50 pages) and click depth (1–6).
  3. Click Start Whole-Site Crawl. Watch live progress and inspect the final broken link table (4xx/5xx error codes), orphan pages, and duplicate metadata.
4

Discover & Cluster Keyword Opportunities

Navigate to the Keywords tab:

  1. Enter a seed topic (e.g. open source seo) and select a country market.
  2. Toggle A-Z expansion or Question modifiers to automatically generate long-tail variants.
  3. Click Discover Keywords. Filter results by intent pills (Informational, Commercial, Transactional) or click semantic clusters to organize content silos.
5

Measure Your AI Visibility (GEO)

Go to the AI Visibility (GEO) tab:

  1. Enter your website domain and your official brand/product name.
  2. Click Run AI Visibility Audit.
  3. neemSEO queries and benchmarks ChatGPT, Claude, Perplexity, Gemini, and Google AI Overviews to calculate your brand's AI Visibility Score (0–100), citation percentage, and specific optimization tips.
Terminal Power

The neemseo CLI Command Suite

Prefer the command line? neemSEO comes with a first-class CLI for CI/CD pipelines, cron jobs, and terminal power users.

1. On-Page Audit neemseo audit

Audit any single URL and output JSON or table results:

neemseo audit https://example.com --keyword "seo tools"
2. Whole-Site Crawl neemseo crawl

Crawl website links with depth limits and sitemap discovery:

neemseo crawl https://example.com --max-pages 50 --max-depth 3
3. Keyword Expansion neemseo keyword

Discover Autocomplete long-tail keywords and topic clusters:

neemseo keyword "open source seo" --country US --expand-az
4. Run Stdio MCP Server neemseo mcp

Launch standard input/output MCP server for AI coding agents:

python -m neemseo.mcp.server
