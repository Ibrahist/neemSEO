# Backlink Profile Analysis Skill

## Goal

Evaluate the domain's backlink health, referring domain diversity, anchor text distribution, and newly acquired or lost links.

## Workflow

1. Call `neemseo_get_backlinks` with the target domain.
2. Analyze the ratio of referring domains to total backlinks.
3. Inspect anchor text distribution to detect over-optimized commercial anchors.
4. Highlight top high-authority referring domains and summarize link growth trajectory.
